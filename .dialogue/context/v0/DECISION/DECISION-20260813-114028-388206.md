Decision (design): Add `deepseek-ocr-vlm` as a distinct loopback-only mlx-vlm adapter using `mlx-community/DeepSeek-OCR-2-8bit`, while retaining the existing `deepseek-ocr` Ollama adapter and configuration until the new integration has been tested. Rationale: migrate away from the Ollama dependency without destructively breaking the proven legacy path. Rejected alternative: replace the existing `deepseek-ocr` adapter and `ollamaHost` configuration in place.
