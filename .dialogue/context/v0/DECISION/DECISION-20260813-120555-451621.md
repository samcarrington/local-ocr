Decision (design): Route only `deepseek-ocr-vlm` through a dedicated loopback-only serial Python service that loads DeepSeek-OCR-2 once and runs image inference on its main thread. Keep GLM-OCR and NuExtract3 on the generic upstream mlx-vlm server. Rationale: the upstream mlx-vlm continuous-batching thread cannot run DeepSeek-OCR-2 image embedding with MLX 0.32 thread-local streams, and version downgrades cannot preserve the application's server contract. Rejected alternative: pinning MLX below 0.31.2. This supersedes the DeepSeek runtime assumption in DECISION-20260813-114028-388206.
