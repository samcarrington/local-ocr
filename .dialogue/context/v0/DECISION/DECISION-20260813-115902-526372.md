Decision (technical): Downgrade the shared pyenv Python installation from MLX 0.32.0 to MLX 0.31.1 rather than create an isolated virtual environment. Rationale: MLX 0.31.2 and newer make GPU streams thread-local, causing the DeepSeek-OCR-2 mlx-vlm continuous-batching server to fail with a missing GPU stream. This supersedes the runtime assumption in DECISION-20260813-114028-388206.
