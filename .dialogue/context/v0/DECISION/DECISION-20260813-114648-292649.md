Decision (design): Replace the engine-specific MLX model server scripts with one `serve:mlx-vlm` command. It selects a configured `--engine` and supports `--model` as an override, while preserving loopback binding checks and configuration-derived host and port. Retain `start:glm-ocr` because it also manages the Nuxt lifecycle. Rationale: the standalone launchers share the same implementation and should not drift.
