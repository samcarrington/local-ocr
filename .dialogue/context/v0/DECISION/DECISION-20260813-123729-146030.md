Decision (design): Defer the DeepSeek-OCR-2 MLX runtime until upstream supplies a compatible release rather than create an isolated compatibility environment. Rationale: the shared supported mlx-vlm runtime uses Transformers 5.14 while the model's trusted processor needs Transformers 4.46-era symbols; the serial runner therefore cannot be made reliable without carrying a separate dependency stack. This supersedes DECISION-20260813-120555-451621.
