Decision (design): Define Markdown, JSON, and HTML in the shared output-format contract, but expose only Markdown until a configured engine explicitly advertises a supported format. Markdown remains canonical; JSON must be schema-validated and HTML sanitised before preview or commit. Rationale: current engines do not establish trustworthy structured or HTML output contracts, so generating formats from Markdown would misrepresent their provenance and broaden the unsafe-output surface. Rejected alternative: universally converting Markdown into JSON or HTML and presenting it as engine output.
